# 🧮 Calculator

A simple and responsive calculator built using HTML, CSS and JavaScript.

## ✨ Features

- ➕ Basic arithmetic operations
- ➖ Addition, subtraction, multiplication and division
- 💯 Percentage calculation
- 🔄 Positive and negative numbers
- 🔢 Decimal numbers
- 🗑️ Delete and clear buttons
- ⌨️ Keyboard support
- 📜 Calculation history
- 💾 History saved using localStorage
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🚀 How to Use

1. Open the calculator in a web browser.
2. Use the buttons to perform calculations.
3. You can also use your keyboard for basic operations.
4. Open the History section to view previous calculations.

## 📚 About the Project

This project was created as a beginner-level frontend project to practice JavaScript functions, DOM manipulation, events and localStorage.
